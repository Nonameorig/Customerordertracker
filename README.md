# 📋 Трекер заказов услуг

Веб-приложение для учёта входящих заказов от клиентов — проекты, сроки, суммы и статусы в одном месте. Работает локально в браузере, без сервера и базы данных.

---

## ✨ Возможности

- **Добавление заказов** — услуга/проект, клиент, контакт, сумма, дедлайн, статус и описание
- **5 статусов** — на согласовании, в работе, на проверке, завершён, отменён
- **Редактирование** — изменение любого поля через модальное окно
- **Удаление с отменой** — toast-уведомление с кнопкой «Отменить» на 5 секунд
- **Поиск** — по названию услуги, клиенту, контакту и описанию
- **Фильтры** — быстрый переход по статусам через чипы
- **Дедлайны** — подсветка: жёлтым за ≤2 дня, красным если просрочен
- **Статистика** — активные заказы, в работе, общий портфель, заработано
- **Сортировка** — активные сверху, внутри — по ближайшему дедлайну
- **Автосохранение** — данные в `localStorage`, не пропадают при закрытии браузера
